<details>
<summary><b>SenseGraph &nbsp;·&nbsp; Apple Swift Student Challenge 2026, Global Winner</b></summary>
<br/>

> A multi-sensory graphing calculator that transforms equations into spatial audio, haptics, and VoiceOver narration. Selected globally by Apple.

| | |
|---|---|
| **Stack** | Swift · SwiftUI · CoreHaptics · AVFoundation · Accessibility |
| **Award** | Apple Swift Student Challenge 2026, Global Winner |
| **Repo** | [aaditaggarwal26/SenseGraph-Swift-App](https://github.com/aaditaggarwal26/SenseGraph-Swift-App) |

Touch the screen and the pitch of a tone tells you exactly where you are on the curve. Haptics fire distinctly at every critical point: a double-click at a zero, a long burst at a maximum, a tremor at an inflection. VoiceOver reads coordinates aloud as you trace. Built on the idea that a graph should be something you can hear and feel, not just look at.

</details>

| | |
|---|---|
| **Stack** | Swift · SwiftUI · AppKit · zsh |
| **Platform** | macOS |
| **Repo** | [aaditaggarwal26/friendlyterminal](https://github.com/aaditaggarwal26/friendlyterminal) |
